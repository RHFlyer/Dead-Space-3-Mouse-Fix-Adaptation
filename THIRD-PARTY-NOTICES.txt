Third-party software in this project
===================================

Raw Input Mouse Fix by slopkhayzo (https://github.com/slopkhayzo/DeadSpace3-RawInputMouseFix)

This mod is based on slopkhayzo's Raw Input Mouse Fix, version 1.1.2. All credit for the fix, and for finding
where Dead Space 3 filters and smooths the mouse, goes to slopkhayzo. This repository is that fix moved onto the
DS3 Mod Loader's mod SDK, plus one setting (UseGameSlider: the game's own mouse sensitivity slider sets the speed).
CHANGELOG.txt lists every change.
